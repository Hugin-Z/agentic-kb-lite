## 2. 架构概览

### 2.1 tier 语义定义

| tier | 语义 | 默认 search 行为 | 典型例子 |
|---|---|---|---|
| **canonical** | 主知识 / 最终交付物 / 客户面前的成品 | ✅ 默认检索 | 最终方案 / 建设方案 / 实施方案 / 需求说明书 / 研究报告 / 政策建议 / 最终汇报 |
| **normal** | 项目内一般材料,无 tier 时的默认值 | ✅ 默认检索 | 纪要 / 调研 / 章节素材 / 一般 .md 笔记 |
| **working** | 过程材料 / 脚本 / 中间产物 | ❌ 默认不检索 | `build_*.py / extract*.py / dump_*.py / 临时实验 / 测试 demo` |
| **versions** | 同系列旧版本,保留追溯 | ❌ 默认不检索 | `v1 / v2 / v3 / 旧稿 / 草稿`(同 family_key 多版本) |
| **assets** | 图片 / 视频 / GIS / zip 等原始素材 | ❌ 默认不检索 | `*.png / *.mp4 / *.shp / *.tif / 248_pages/ / appendix/` |

### 2.2 物理目录映射

```text
corpus/01-projects/<项目名>/
├── 01-方案/                  # canonical + normal 项目方案类
├── 02-章节/
├── 03-纪要/                  # normal 纪要
├── 04-调研/                  # normal 调研
├── 05-附图/                  # normal 项目附图(少量重要图)
├── 99-其他/
└── .staging/                 # v0.3 新增,默认 search 排除
    ├── working/             # 过程脚本 / 临时材料
    ├── versions/            # 旧版本(family_key 分组)
    │   ├── <family_key_A>/
    │   └── <family_key_B>/
    └── assets/              # 大量原始素材(png / mp4 / shp / zip / *_pages/)
```

`.staging/` 命名不用 `.archive/` 原因:
- `corpus/04-archives/` 已是 PARA 顶层归档(整项目级)
- `项目/.archive/` 跟顶层同名容易混淆;`.staging/` 语义清晰("待整理 / 低优先暂存区")

### 2.3 AI 语义路由协议升级

## 3. Review 协议(沿用 v0.2 同款 + Codex 门禁)

1. **自查**:Hugin 对照阶段末尾的 Review 检查清单,逐条标 YES / NO / 部分

#### 步骤 2.1: `_build_target_dir` 支持 tier 路由

```python
def _build_target_dir(item: dict) -> Path:
    bucket = item["target_bucket"]
    tier = item.get("tier", "normal")  # v0.3 默认 normal
    
    if bucket != "01-projects":
        # areas / resources / archives 不走 tier(只 projects 有 .staging)
        return CORPUS / bucket / item.get("target_subdir", "")
    
    proj_root = CORPUS / bucket / item["target_project"]
    
    if tier in ("canonical", "normal"):
        return proj_root / item["target_subdir"]
    elif tier == "working":
        return proj_root / ".staging" / "working" / item["target_subdir"]
    elif tier == "versions":
        return proj_root / ".staging" / "versions" / item["family_key"]
    elif tier == "assets":
        return proj_root / ".staging" / "assets" / item["target_subdir"]
    else:
        raise ValueError(f"unknown tier: {tier}")
```

**注**:areas / resources / archives bucket 不走 tier(只 projects 有 .staging 子目录;非 projects 类材料本身就是参考资料 / 跨项目素材,不需要 staging 分层)。

# ====================== Layer 6:tier 字段校验(v0.3 新增)======================
ALLOWED_TIERS = {"canonical", "normal", "working", "versions", "assets"}
tier = item.get("tier")
if tier is not None:
    if not isinstance(tier, str):
        raise ValueError(f"tier must be str, got {type(tier).__name__}")
    if tier not in ALLOWED_TIERS:
        raise ValueError(f"tier '{tier}' not in whitelist {sorted(ALLOWED_TIERS)}")
    if tier == "versions":
        fk = item.get("family_key")
        if not isinstance(fk, str) or not fk.strip():
            raise ValueError("tier='versions' requires non-empty family_key")
