## 2. 架构概览

### 2.1 tier 5 类语义定义

| tier | 语义 | 默认 search 行为 | 典型例子 |
|---|---|---|---|
| **canonical** | 主知识 / 最终交付物 / 客户面前的成品 | ✅ 默认检索 | 最终方案 / 建设方案 / 实施方案 / 需求说明书 / 研究报告 / 政策建议 / 最终汇报 |
| **normal** | 项目内一般材料,无 tier 时的默认值 | ✅ 默认检索 | 纪要 / 调研 / 章节素材 / 一般 .md 笔记 |
| **working** | 过程材料 / 脚本 / 中间产物 | ❌ 默认不检索 | `build_*.py / extract*.py / dump_*.py / 临时实验 / 测试 demo` |
| **versions** | 同系列旧版本,保留追溯 | ❌ 默认不检索 | `v1 / v2 / v3 / 旧稿 / 草稿`(同 family_key 多版本) |
| **assets** | 图片 / 视频 / GIS / zip 等原始素材 | ❌ 默认不检索 | `*.png / *.mp4 / *.shp / *.tif / 248_pages/ / appendix/` |

**v1.1 强调**:tier 是 **5 类**(不是 4 层)。v1.0 多处写"4 层"是笔误,v1.1 全文统一为"5 类"。

### 2.2 物理目录映射(v1.1 扩到 projects + areas + resources 三个 bucket)

#### projects bucket

```text
corpus/01-projects/<项目名>/
├── 01-方案/                  # canonical + normal 项目方案类
├── 02-章节/
├── 03-纪要/                  # normal 纪要
├── 04-调研/                  # normal 调研
├── 05-附图/                  # normal 项目附图(少量重要图)
├── 99-其他/
└── .shelved/                 # v0.3 新增,默认 search 排除
    ├── working/             # 过程脚本 / 临时材料
    ├── versions/            # 旧版本(family_key 分组)
    │   ├── <family_key_A>/
    │   └── <family_key_B>/
    └── assets/              # 大量原始素材(png / mp4 / shp / zip / *_pages/)
```

#### areas bucket(v1.1 新增 tier 适用)

```text
corpus/02-areas/<subdir>/      # subdir = 产品方案库 / 投标章节模板 / ...
├── <canonical/normal 材料>
└── .shelved/                  # v1.1 新增:每个 areas subdir 内独立 .shelved
    ├── working/
    ├── versions/<family_key>/
    └── assets/
```

#### resources bucket(v1.1 新增 tier 适用)

```text
corpus/03-resources/<subdir>/  # subdir = 国标行标 / 行业研究 / 竞品资料 / 培训与调研
├── <canonical/normal 材料>
└── .shelved/                  # v1.1 新增:每个 resources subdir 内独立 .shelved
    ├── working/              # 罕见(资源类很少有 working)
    ├── versions/<family_key>/  # 国标 v1/v2 之类
    └── assets/               # 竞品动画 / 培训视频 / 老 PPT 大文件
```

#### archives bucket(不变)

```text
corpus/04-archives/<项目名>/   # PARA 归档层,本身就默认不在 P+A+R 全扫;不需要 .shelved
```

**v1.1 拍板理由**(B 分散 vs A 集中):
- B 分散:每个 subdir 内独立 .shelved,保留 subdir 语义(`国标行标/.shelved/versions/` 与 `竞品资料/.shelved/assets/` 不混)
- A 集中:顶层一个 .shelved,结构简单但 subdir 语义丢失
- **Codex 倾向 B,Hugin v1.1 拍 B**

**`.shelved/` 命名理由**(v1.1 修订):
- `corpus/04-archives/`:PARA 顶层归档(整项目级,已交付不再用)
- `项目/.archive/`:跟顶层同名容易混淆(v1.0 备选,Codex 5 条点出)
- `项目/.staging/`:语义模糊("待发布 / 待处理"含义太多,Codex 5 条点出)
- **`项目/.shelved/`**:语义清晰("搁置 / 低优先暂存区,默认不搜"),与 archives 区分明确

### 2.3 AI 语义路由协议升级

v0.2.0 PARA 路由协议 Step A-D(explicit_mappings / 顶层 / 子目录脱钩 / 单文件 5 子目录),v0.3 加 **Step E:tier 判定**(在 Step D 之后,落 routing_plan.json 之前)。

详细 Step E 见阶段 1 步骤 1.2。

#### 步骤 1.4: REQUIRED_FIELDS_SCHEMA 扩 Layer 6(v1.1 明确必填语义)

```python
# v0.2.2 6 字段沿用(全部必填非空)
REQUIRED_FIELDS_SCHEMA = {
    "src_abs":         {"type": str,  "non_empty": True},
    "target_bucket":   {"type": str,  "non_empty": True},
    "target_subdir":   {"type": str,  "non_empty": True},
    "target_filename": {"type": str,  "non_empty": True},
    "frontmatter":     {"type": dict, "non_empty": False},
    "ai_reason":       {"type": str,  "non_empty": True},
}

# v0.3 新增:tier 字段(v0.3 新 plan 必填,v0.2 旧 plan 默认 normal)
ALLOWED_TIERS = {"canonical", "normal", "working", "versions", "assets"}

def _validate_tier_field(item: dict, plan_schema_version: str | None) -> None:
    """Layer 6:tier 字段校验(v0.3 新增)
    - plan_schema_version == 'v0.3':tier 必填非空 + 必在白名单
    - plan_schema_version 缺失 / != 'v0.3':tier 可缺(默认 normal),给值时仍校验白名单
    - tier == 'versions':family_key 必填非空 + 不含 Windows 非法字符
    """
    is_v03 = (plan_schema_version == "v0.3")
    tier = item.get("tier")
    if tier is None:
        if is_v03:
            raise ValueError(
                "v0.3 plan_schema_version requires tier field (missing). "
                "Set tier in {canonical, normal, working, versions, assets}."
            )
        return  # v0.2 兼容:tier 缺 → 默认 normal(由 _build_target_dir 兜底)
    if not isinstance(tier, str):
        raise ValueError(f"tier must be str, got {type(tier).__name__}")
    if not tier.strip():
        raise ValueError("tier must not be empty string")
    if tier not in ALLOWED_TIERS:
        raise ValueError(f"tier '{tier}' not in whitelist {sorted(ALLOWED_TIERS)}")
    if tier == "versions":
        fk = item.get("family_key")
        if not isinstance(fk, str) or not fk.strip():
            raise ValueError("tier='versions' requires non-empty family_key")
        # v0.3 Codex-7 反馈:family_key 是路径段,Windows 非法字符必须拒
        WIN_INVALID = set('<>:"|?*\\/')
        bad = WIN_INVALID & set(fk)
        if bad:
            raise ValueError(
                f"family_key contains Windows-invalid chars {sorted(bad)}: {fk!r}"
            )
```

**Layer 6 三层校验**:

| 层 | 触发 | 行为 |
|---|---|---|
| **6.1 必填判定** | `plan_schema_version == 'v0.3'` | tier 缺失 → 拒 |

#### 步骤 2.1: `_build_target_dir` 支持 tier 路由(v1.1 三 bucket + defense-in-depth)

```python
def _build_target_dir(item: dict) -> Path:
    """v0.3:三 bucket(projects/areas/resources)支持 tier 路由 → .shelved/<tier>/
    v1.1 Codex-8 反馈:保留 v0.2 defense-in-depth(resolve + relative_to + multi-level split)"""
    bucket = item["target_bucket"]
    tier = item.get("tier", "normal")  # v0.2 旧 plan 兜底默认 normal

    if bucket == "04-archives":
        # archives 不走 tier(已是 PARA 归档层)
        target_dir = CORPUS / bucket / item.get("target_project", "")
    elif tier in ("canonical", "normal"):
        # 主知识 / 一般材料走现有结构
        if bucket == "01-projects":
            target_dir = CORPUS / bucket / item["target_project"] / item["target_subdir"]
        else:
            # areas / resources:CORPUS/bucket/<subdir 可多级>
            target_dir = CORPUS / bucket
            for seg in item["target_subdir"].strip("/").split("/"):
                target_dir = target_dir / seg
    elif tier in ("working", "assets"):
        # 三 bucket 都有 .shelved/<tier>/
        if bucket == "01-projects":
            target_dir = (CORPUS / bucket / item["target_project"]
                          / ".shelved" / tier / item["target_subdir"])
        else:
            # areas / resources:CORPUS/bucket/<subdir 可多级>/.shelved/<tier>/
            target_dir = CORPUS / bucket
            for seg in item["target_subdir"].strip("/").split("/"):
                target_dir = target_dir / seg
            target_dir = target_dir / ".shelved" / tier
    elif tier == "versions":
        # versions 用 family_key 分组(family_key 是 Layer 6.3 已校验的安全字符串)
        family_key = item["family_key"]
        if bucket == "01-projects":
            target_dir = (CORPUS / bucket / item["target_project"]
                          / ".shelved" / "versions" / family_key)
        else:
            target_dir = CORPUS / bucket
            for seg in item["target_subdir"].strip("/").split("/"):
                target_dir = target_dir / seg
            target_dir = target_dir / ".shelved" / "versions" / family_key
    else:
        raise ValueError(f"unknown tier: {tier}")

    # v0.2.1 P0-2 defense-in-depth 保留:确保 target_dir 在 CORPUS 内
    resolved = target_dir.resolve()
    try:
        resolved.relative_to(CORPUS.resolve())
    except ValueError:
        raise ValueError(
            f"resolved target_dir escapes CORPUS: {resolved} (CORPUS={CORPUS.resolve()})"
        )
    return target_dir  # 返回未 resolve 的 Path,保留 .shelved 等相对结构展示
```

**关键防御**:
- multi-level subdir split(`.strip("/").split("/")`)避免 areas/resources 的多级 subdir 被当字面量
